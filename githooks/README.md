# Git hooks (Cursor / AI trailer cleanup)

These hooks keep Cursor/AI attribution out of GitHub commit messages.

| Hook | Behavior |
|------|----------|
| `commit-msg` | Strips forbidden trailer lines from the commit message before the commit is created |
| `pre-push` | **Blocks** the push if any commit in the range still has those trailers |

## Enable (required once per clone)

From the repository root:

```bash
git config core.hooksPath githooks
```

Confirm:

```bash
git config --get core.hooksPath
# should print: githooks
```

On Windows, use **Git Bash** (or Git for Windows) so the `#!/usr/bin/env bash` hooks run.

## Forbidden trailer examples (stripped / blocked)

- `Co-authored-by: Cursor <cursoragent@cursor.com>`
- `Made-with: Cursor`
- `Generated by Cursor` / `Generated with Claude` / Copilot co-author trailers
- Bare `https://cursor.com` footer lines

Source file contents are **not** scanned (avoids false positives on normal code).
